# JMeter Load Testing — DummyJSON API

## О проекте

Учебный проект по нагрузочному тестированию API с использованием Apache JMeter.

## Технологии

- Apache JMeter 5.6.3
- Java 17
- JMeter Plugins
- DummyJSON API

## Тестовый сценарий

1.  01_Login — авторизация пользователя
2. 02_Get_Curent_User — получение данных текущего пользователя
3. 03_Get_Products — получение списка товаров
4. 04_Search_Products — поиск товаров
5. 05_Get_Carts — получение корзин
6. 06_Get_Cart — получение конкретной корзины

## Виды нагрузочного тестирования

### Линейная нагрузка

- Максимальная нагрузка: 20 пользователей
- Продолжительность: 10 минут
- Плавное увеличение нагрузки
- Ошибки: 3,93%

### Ступенчатая нагрузка

- 3 ступени
- 10 → 15 → 20 пользователей
- Длительность ступени: 3 минуты
- Ramp-up: 20 секунд
- Ошибки: 0,38%

## Результаты
*Линейная нагрузка*

Выполнено **30 175 запросов**. 
Среднее время ответа составило 188 мс, медианное — 100 мс, P95 — 513 мс, P99 — 1645 мс. Максимальное время ответа составило 6341 мс.

Наибольшие задержки показал Login: среднее время ответа — 567 мс, P95 — 2080 мс, P99 — 2113 мс, максимальное — 5004 мс. 

При этом Get_Curent_User продемонстрировал максимальное единичное время ответа — 6341 мс, несмотря на среднее время ответа 131 мс.

По данным Aggregate Report, **общий уровень ошибок составил 3,93%**. При этом в View Results Tree явных failed-запросов среди просмотренных результатов не обнаружено, поэтому причина зафиксированных ошибок требует дополнительного анализа.

Таким образом, при линейной нагрузке система в целом сохраняла относительно низкое среднее время ответа, однако наблюдались значительные задержки в хвосте распределения, особенно для Login, а также ненулевой уровень ошибок, зарегистрированный JMeter.





*Ступенчатая нагрузка*

Выполнено **2643 запроса**.
Среднее время ответа составило 150 мс, медианное — 99 мс, P95 — 331 мс, P99 — 501 мс. 
Массового роста времени ответа при выполнении теста не наблюдается.
Наибольшие задержки показал **Login**: P95 — 501 мс, P99 — 1623 мс, максимальное время — 2168 мс. 
Общий **уровень ошибок** составил **0,378%**; для отдельных запросов зафиксированы SSL/TLS handshake errors, в том числе SSLHandshakeException: Remote host terminated the handshake. 

Таким образом, система в рамках заданной ступенчатой нагрузки в **целом сохраняла стабильное время ответа**, однако тест нельзя считать полностью безошибочным из-за наличия отдельных ошибок соединения.
